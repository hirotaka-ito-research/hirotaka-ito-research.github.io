Job market paper

Asymptotic Minimax Optimality of Set Estimation

Parameters of interest are often expressed as transformations of partially identified raw parameters. In such settings, the identified set of the targeted objects can be non-convex and there are no theoretical results on how well one can learn it from data. This paper fills part of this gap by studying the asymptotic efficiency of set estimation for a general class of identified sets. I first derive the asymptotic minimax efficiency bound for set estimators under risk functions based on the Hausdorff metric. A key ingredient in the analysis is a limit experiment framework tailored to the local structure of the identified set. I then show that a set estimator based on a criterion function is efficient under mild conditions. The analysis requires deriving the limiting distribution of the set estimator in the Hausdorff metric, which I obtain without globally characterizing the identified set via its support functions. Based on the limiting distribution, I propose a bootstrap-based confidence set. I illustrate my framework with an application to optimal taxation with behavioral agents.

Uniform and Locally Adaptive Quasi-Bayesian Inference for Conditional Moment Models

This paper proposes a quasi-Bayesian method to construct confidence bands for a nonparametric function in conditional moment models. Importantly, we allow the true function to possess inhomogeneous smoothness over its domain, reflecting the locally varying complexity of the function of interest. Our confidence bands are constructed from quasi-Bayes posteriors with sieve GMM criterion functions and spike-and-slab priors. We show that the quasi-Bayes posteriors contract to the true function in the supremum norm at a rate that adapts to the unknown local smoothness. Based on this result, we derive a nonparametric Bernstein–von Mises-type result for the quasi-Bayes posteriors, in which the well-known covariance mismatch is avoided through the use of GMM criterion functions. The resulting confidence bands are shown to achieve exact asymptotic coverage, while their widths, measured in the supremum norm, shrink at a nearly locally adaptive rate.
